## ⚠️ قرارات تقنية مهمة (لا تُغيَّر)

1. **عدم استخدام Domain Lock** في الـ obfuscation
2. **عدم انتهاء صلاحية** (no expiration) للـ tool
3. **WASM Wrapper** للحماية المتعددة الطبقات (P6 Analyzer Protected version)
4. **AES-256-GCM** للتشفير
5. **NG SA: 6 شهادات إلزامية** (ليس 4): EHC → ECC → TCC → RTR → PAC → FAC
6. **PercentComplete في P6 = decimal 0-1** (وليس 0-100)
7. **Duration في P6 = ساعات** (ليس أيام، يحتاج HoursPerDay من Calendar)
8. **Critical Path ≠ Longest Path** — استخدم network DP وليس reduce/sum
9. **Saudi Hijri**: لا تستخدم 11-day approximation (السنة 354.367 يوم، رؤية الهلال ±1-2 يوم)
10. **LOE patterns**: Level of Effort, LOE, TT_LOE
11. **Tests pattern**: استخراج real helpers من source HTML (لا parallel definitions)
12. **Push policy**: Docs-only direct push, code changes via branch + PR
13. **اللغة**: عربي + مصطلحات إنجليزية، نسبة الدقة في بداية كل رد
14. **Auto-increment patch version**: v29.0.11 → v29.0.11.1 لكل تعديل
15. **Conventional Commits**: feat/fix/docs/refactor/test/chore
