## ✅ M3 — getActualPctRatio Fallback

### Required check:
```bash
grep -n "getActualPctRatio" -A40 p6-analyzer.html
```

### Evidence (lines 7268-7287):
```javascript
const getActualPctRatio = (p) => {
  if (!p) return 0;
  const type = (p.pctType || "").toLowerCase();
  let raw;
  if (type === "physical") raw = p.physicalPct;
  else if (type === "duration") raw = p.durationPct;
  else if (type === "units") raw = p.unitsPct;
  else if (type === "manual") raw = p.pctComplete;
  else {
    // Unknown/missing pctType: fall back to first available, preserve 0 with ??
    raw = p.pctComplete ?? p.durationPct ?? p.physicalPct ?? p.unitsPct ?? 0;
  }
  if (raw === null || raw === undefined || isNaN(raw)) return 0;
  const num = Number(raw);
  return Math.max(0, Math.min(1, num));
};
```

### Verified:
- ✅ Switches on `pctType` (Physical/Duration/Units/Manual)
- ✅ Uses `??` (nullish coalescing) NOT `||` for fallback (preserves 0)
- ✅ Handles null/undefined/NaN safely
- ✅ Clamps to [0, 1]
